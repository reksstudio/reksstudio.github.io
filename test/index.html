The bottleneck

Equations no one derives by hand. Ours are generated.

An intact bond holds two electrons in one orbital. As it breaks, they spread over two orbitals, one each. REKS, a density functional method, follows the change: 2 and 0 become 1 and 1. Working equations outgrow hand derivation; (4,4) was the largest reported.

HKK′ ≠ 0, K ≤ K′

One equation: one nonzero Hamiltonian matrix element between configurations K and K′ of one spin sector (each pair once), an algebraic expression the engine writes.

Why it's fast

REKS Studio computes the two-electron integrals and the DFT grid once per calculation and reuses them across every microstate; each configuration's Fock matrix is assembled by weighted addition, not by an independent KS-DFT calculation. Cost against DFT →

This is the whole input

#! SA-REKS(2,2) and SI-SA-REKS(2,2) of H2, BH&HLYP/cc-pVDZ, default SA and SI pools.

molecule h2 {
0 1
H 0.0 0.0 0.0
H 0.0 0.0 0.74
symmetry c1
}

set {
  basis      cc-pvdz
  reference  reks
  reks       [2, 2]
}

energy('bhhlyp')

Install from source (build guide):

# clone the branch
git clone --branch kk/reks.studio https://github.com/ConstLike/psi4.git
cd psi4

# set up build dependencies
conda env create -f environment.yml -n p4env311
conda activate p4env311

# configure and build
cmake -S. -Bobjdir -DCMAKE_INSTALL_PREFIX=/path/to/install
cmake --build objdir --target install -j$(nproc)
