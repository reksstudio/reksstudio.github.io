Installing REKS Studio and configuring an ensemble

A working reference for building the package and controlling the state-averaged and state-interaction ensembles it runs. For the method itself — why REKS Studio exists and how it stays fast — see the overview page.

Installation

REKS Studio is currently a development branch of Psi4, not yet a standalone package or conda release. Building it follows Psi4's own CMake-based build process. A working-equations catalogue is generated and compiled in automatically — nothing extra to run afterward.

# clone the branch
git clone --branch kk/reks.studio https://github.com/ConstLike/psi4.git
cd psi4

# set up build dependencies
conda env create -f environment.yml -n p4env311
conda activate p4env311

# configure and build
cmake -S. -Bobjdir -DCMAKE_INSTALL_PREFIX=/path/to/install
cmake --build objdir --target install -j$(nproc)
Note. This branch is research software under active development. Interfaces and keyword names may change before it's merged upstream.

Running a job

Once built, REKS runs as an ordinary Psi4 reference — no separate binary or import. Set reference to reks, give the active space as [N, M], and call psi4.energy() as usual.

import psi4

mol = psi4.geometry("""
0 1
C 0.000000 1.301509 -2.315529
C 0.000000 -1.301509 -2.315529
...
units bohr
""")

psi4.set_options({
  "basis": "aug-cc-pVTZ",
  "reference": "reks",
  "reks": [4, 4],

  "sa_reks_configs": ["PPS1", "OSS1", "OSS2"],
  "sa_reks_extra": [[1, 1, 1, 1, 0, 0, 0, 0]],
  "si_reks_configs": ["PPS1", "OSS1", "OSS2", "OSS3", "OSS4"],
})

E, wfn = psi4.energy("bhhlyp", return_wfn=True)

Keyword reference

Every keyword below has a REKS_*-prefixed alias (e.g. sa_reks_configs / reks_sa_configs) — set one or the other, never both. Defaults are noted where a keyword can be left out entirely.

Reference & active space

reference

Set to reks to enable the method.

reks[N, M]

Active space as electrons and orbitals. Molecule multiplicity follows the canonical value automatically — spin manifolds are chosen through the SA/SI keywords below, not the molecule block.

Note. Each (N, M) is backed by a pre-generated configuration catalogue shipped with REKS Studio (currently (2,2), (4,4) and (6,6)). Requesting an active space with no catalogue on disk fails at load time — it isn't assembled on the fly.

Configuration names & bulk tokens

Every configuration in the catalogue has a name of the form <TYPE><index>, e.g. PPS1, OSS2, T_PPS3, DOSS_SPS1_0. You rarely need the full list — an unknown name in a config keyword makes REKS Studio print every valid name and type for your active space — but the type prefixes are worth knowing:
PPS

The perfectly-paired singlet — the closed-shell-like reference configuration (every geminal in generation 0). Every catalogue has at least one.

OSS, DOSS, TOSS, QOSS …

Configurations with 1, 2, 3, 4 … open-shell-singlet geminals (generation 1 and up).

DES, DDES, TDES, QDES …

The same 1, 2, 3, 4 … ladder, but for doubly-excited closed-shell geminals rather than open-shell ones.

T_ prefix

Marks a configuration as belonging to the sector's triplet background rather than the singlet manifold, e.g. T_PPS3.

SPS tag

Marks a spin-projected configuration, built from one parent expansion — appears combined with other markers, e.g. DOSS_SPS1_0.

Anywhere a config name is expected — in sa_reks_configs or si_reks_configs — these bulk tokens also work, so you rarely have to spell out individual names:
"full"

The entire configuration block of that manifold.

a type name"PPS", "OSS", "DOSS" …

Every configuration of that type in the manifold.

"single-scheme:N"

Every configuration of geminal-pairing scheme N (default scheme 0). Several indices can be unioned: "single-scheme-1-2-3".

"mixed-scheme:N"

The SSR state set on scheme N — that scheme's single-excitation configs plus every open-shell-singlet config of the manifold.

"sps"

Just the spin-projected base configurations.

a pattern"*" / "?"

Every configuration name it glob-matches.

"exclude:X"SI cassettes only

Subtracts whatever X names (any token above) from the rest of the cassette, e.g. ["full", "exclude:sps"]. An SA block, being a weighted list rather than a set, doesn't accept exclude:.

Note. A PSithon (.dat) input can't use a literal : inside an array element — write scheme indices with - or _ instead, e.g. single-scheme-1-2.

State-averaged (SA) ensemble

The configurations whose orbitals are jointly optimized in the SCF step.
sa_reks_configsalias: reks_sa_configs

The SA configuration pool — a flat list for one spin manifold, or a list of lists to declare a block per manifold. Left unset, a sensible default pool is used for the active space's lowest manifold.

sa_reks_2spinalias: reks_sa_2spin

Which spin manifold(s) the SA blocks belong to, as 2S values. Only needed when more than the default manifold is in play.

sa_reks_weightsalias: reks_sa_weights

Weight for each SA pool entry, configurations first, then any extra determinants. Must be non-negative and sum to 1. Left unset, weights are distributed equally.

sa_reks_extraalias: reks_sa_extra

Extra determinants — such as a high-spin state — given as explicit occupation vectors. Each carries its own SA weight to help SCF convergence, but is excluded from the SI step.

State-interaction (SI) ensemble

Defined independently of the SA pool — mixed afterward to produce the final multi-state energies.
si_reks_configsalias: reks_si_configs

The SI configuration groups ("cassettes") that form the secular equations. Left unset, one cassette spans the full config block of the lowest manifold.

si_reks_2spinalias: reks_si_2spin

Which spin manifold each SI group belongs to, mirroring sa_reks_2spin.

si_reks_report_statesalias: reks_si_report_states

Caps how many SI states are reported per cassette. All downstream per-state properties (natural orbitals, dipoles, RDMs) are computed only for the reported states. Left unset, every state is reported.

Guesses & restarts

REKS jobs converge far more reliably from a previous wavefunction than from a cold guess, so most production runs are chained restarts. Restarting itself uses ordinary Psi4 machinery; the two keywords below refine where in the read guess the active space lands.
# load a checkpoint, tell SCF to use it, save a new one
old_wfn = psi4.core.Wavefunction.from_file("prev.wfn.npy")
psi4.set_options({"guess": "read", "df_scf_guess": False, ...})
E, wfn = psi4.energy("bhhlyp", restart_file="prev.wfn.npy", return_wfn=True)
wfn.to_file("next.wfn")
guess_mo_swaps

Reorder columns of the read guess before SCF, as comma-separated swap pairs ("HOMO-1 HOMO, LUMO+2 LUMO+3"). Applies to alpha and beta identically. C1 symmetry only.

guess_active_window

REKS-only: fills just the active-space columns from the read guess, one token per active orbital in active-column order — the targeted fix when a restart's active window lands on the wrong orbitals. Mutually exclusive with guess_mo_swaps. Requires guess read.

Tip. If SCF converges instantly to a suspiciously wrong energy right after a restart, this is almost always the symptom — check the Molden output, then fix the active window rather than the whole guess.

Fractional occupation numbers (FONs)

Each geminal pair carries FONs (n_p, n_q) with n_p + n_q = 2, optimized every SCF iteration between the closed-shell and fully-open limits.
reks_fon_interp_delta

Interpolation parameter δ bridging the closed- and open-shell limits of each geminal. Default 0.4.

reks_n_fon … reks_z_fon8 keywords, one per FON generation

A lower bound on every active FON of that generation. Setting reks_m_fon: 1.0, for instance, restricts every generation-1 (OSS) geminal FON to [1.0, 2 − 1e-8] — it stays free to vary and is optimized within that range, it is not fixed at n_p = n_q = 1. Negative (the default) disables the bound. Useful when an open-shell-type configuration keeps collapsing back toward closed-shell during a difficult convergence.

Delocalization penalty

An optional energy term that discourages active orbitals from spreading over many atoms — useful for steering SCF toward a localized diradical/pair solution.
reks_deloc_ipr_penalty

Coefficient λ (Ha) of an inverse-participation-ratio penalty on the active orbitals' atomic populations. Default 0.0 (off).

reks_deloc_ipr_method

Population analysis used by the penalty: LOWDIN or MULLIKEN. Default LOWDIN.

Solver & convergence

Three cooperating engines drive REKS's orbital/FON optimization — a plain level-shifted burn-in, an optional trust-region warmup, and the GVB-DIIS accelerator that normally finishes the job. Defaults work well for most systems; most users only ever touch level_shift.
reks_use_trah

Use trust-region (TRAH) orbital+FON optimization as a warmup before GVB-DIIS takes over, or as the whole SCF if reks_gvb_diis is off. Default false.

reks_gvb_diis

Use the GVB-DIIS accelerator (Muller et al. 1994) for orbital optimization — the default engine. Default true.

reks_diis_formulation"CFM" | "ORBITAL"

ORBITAL (default) extrapolates skew-symmetric rotation generators directly and skips Fock diagonalization each step. CFM extrapolates the composite multishell Fock matrix instead, closer to the original GVB-DIIS formulation.

reks_gvb_diis_start

SCF iteration at which GVB-DIIS takes over from the burn-in (or from TRAH). Default 3.

level_shift_adapt

When true (default), REKS's pair-aware staircase level shift decays toward a floor when orbital mixing is small and grows back toward your level_shift when GVB-pair scrambling is detected. False freezes it at your literal level_shift every iteration.

Note. Beneath these sit roughly thirty further reks_diis_* / reks_gvb_* knobs — angle filtering, SVD conditioning, rewind/restart monitors, a bounded Newton-Krylov "miniTRAH" episode for stalls — that fire automatically and are tuned by the developers. Reach for them only when a specific pathology shows up; raise reks_report_level to 4 first to see which monitor is actually firing.

Reporting

reks_report_level1–5

Verbosity of the run report. 1 = fatal diagnostics only. 2 (default) = setup, pools, SCF trace, adiabatic states, and the 15 lowest microstate energies. 3 = the full microstate list plus config-axis wavefunction arrays. 4 = per-iteration solver traces and wide SI matrices. 5 = matrices over the config, microstate, and orbital axes too.

Troubleshooting

Common convergence symptoms and where to look first.

Instant convergence to a wrong energy after restart

The active window likely landed on the wrong orbitals from the read guess. Check the Molden output, then fix with guess_active_window.

Hits maxiter without converging

With fail_on_maxiter: false you still get a wavefunction back — save it and restart from it rather than starting over. Raise reks_report_level to 4 to see which monitor is firing.

SCF oscillates or cycles

Try reks_use_trah: true as a more robust warmup, or switch reks_diis_formulation between ORBITAL and CFM.

A geminal keeps collapsing to closed-shell

Floor its generation's FON with the matching reks_*_fon keyword — see Fractional occupations.

Active orbitals delocalize over the whole molecule

Try a positive reks_deloc_ipr_penalty.

Unknown config name/type, or an (N, M) that fails to load

REKS Studio's own error lists every valid name for your active space; an unrecognized (N, M) simply has no catalogue shipped yet.
