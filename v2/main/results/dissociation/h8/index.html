Calculations

The REKS/SSR calculations for the hydrogen chains were executed using a state-averaged ensemble that included the PPS1 configuration and all OSSx configurations generated within the same GVB orbital pairing scheme. To ensure stable SCF convergence, a high-spin determinant was incorporated into the ensembles. All density functional calculations utilized the BH&HLYP functional. For the REKS/SSR calculations, initial guess orbitals were generated via standard KS-DFT calculations using the identical density functional and basis set. Potential energy curves were scanned at increments of 0.01–0.025 Å. Additionally, reference full configuration interaction calculations were carried out using the Psi4 package.
