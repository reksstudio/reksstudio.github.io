Definitions

Configuration: one antisymmetrized product of the core and one geminal per active electron pair; the SI of a spin sector diagonalizes the Hamiltonian over all configurations of its catalogue. SI configurations per 2S: the number the output prints for each spin sector of the job.

Setup and provenance

Setup

Method
SA-REKS(M,M), ensemble PPS + OSSs + all-α determinant; SI-SA-REKS over the full catalogue of each spin sector the input lists; every root the output prints
Sets
TNS: 6-31G(d) · BH&HLYP REKS(12,12); 6-31G(d) · HF REKS(12,12); def2-TZVP · BH&HLYP REKS(12,12); def2-TZVP · HF REKS(12,12). TTR: cc-pVTZ · BH&HLYP REKS(4,4), (6,6), (8,8), (10,10); def2-TZVP · BH&HLYP REKS(4,4), (6,6), (8,8), (10,10)
Starting orbitals
TNS REKS(12,12), 6-31G(d): ROHF 2S + 1 = 13 orbitals, each paired with its Coulson–Rushbrooke partner; TNS def2-TZVP: the converged 6-31G(d) orbitals projected to the larger basis; TTR: a converged run of the same or a neighbouring active space, in the search order of the input
Geometries
TNS: triangulene-nanostar_idealized.xyz (Hieulle et al. 2021); TTR: butterfly_nanographene.xyz (Song et al. 2024); both planar
Code
Psi4 branch kk/reks.v42, the commit of each job on its run line; PC-1: conda-forge GCC 15.2, Intel MKL, -march=native; PC-2: Intel MKL

Reference

Experiment and models: Hieulle et al. 2021; Song et al. 2024.

Scope: Calculated values: these calculations, gas phase. Experiment: values as printed in the cited papers, measured on Au(111).
