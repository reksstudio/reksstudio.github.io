Peak memory

Setup

System
Tetracene dimer (TTRCN2), C36H24, 60 atoms; DR = interplanar displacement of the monomers. TO, open shell: DR −0.40 Å, SA-REKS(2,2) occupations 1.71 / 0.29 in 6-31G(d), 1.76 / 0.24 in def2-TZVP; TC, closed shell: DR 0 Å, SA-REKS(2,2) occupations 2.00 / 0.00.
Bases
6-31G(d), 552; def2-TZVP, 1260 basis functions, spherical, the same count in all three codes.
Protocol
Zeroth calculation at the seed geometry, DR 0.01 Å away, untimed; the timed run reads its orbitals. SCF and SCF + states are separate jobs. Wall = whole program run, start-up included.
Settings
Default settings of each code except what was set for all: basis, BH&HLYP, SG-1 grid (ORCA DefGrid2, it has no SG-1), density-fitted integrals (Psi4 DF, ORCA RIJCOSX, Q-Chem RI-J/RI-K), SCF convergence energy 1e-8 / density (error) 1e-7, at most 150 SCF cycles, response convergence 1e-6, 10 roots, 36 cores, 300 GB. REKS rows marked † ran at e 1e-7, d 1e-6 (TC (10,10), TC def2-TZVP (8,8), (10,10)).
Hardware
2x Xeon Gold 6240, 36 cores; 36 threads or MPI ranks and 300 GB for every code.
Repeats
ORCA and Psi4 3; Q-Chem 3 where its wall time is within 1.5x of the faster of ORCA (same method) and SA-REKS(2,2), else 1. Shown: the fastest converged repeat.
Too slow
a Q-Chem run still going past both 2 x max(ORCA with the same method, slowest REKS job of the molecule) and 1 h is killed; every finished run keeps its numbers.
Memory
Peak PSS summed over the process tree, sampled every 0.5 s; GiB.
Energies
RKS energies of the three codes agree within 1.8 mEh.
Builds
REKS rows: kk/reks.v42 @ cf0bacc93 (TC def2-TZVP (8,8): 3eb094626); Psi4 RKS/UKS: 2acf2c145.

Inputs, TO (open shell, 6-31G(d)); seeds not shipped

  • reks_sa66.py: SA-REKS(6,6): threads and memory from the environment (OMP_NUM_THREADS, PSI4_MEMORY); seed orbitals read from prev.npy (not shipped).
  • reks_si66.py: SI-SA-REKS(6,6), 10 states: environment and prev.npy seed as for SA-REKS(6,6).
  • orca_sftda.inp: ORCA SF-TDA, 10 roots: %pal nprocs 36 and %maxcore 8333 (MB per rank) set in the input; seed prev.gbw read by MORead (not shipped).
  • qchem_sftda.in: Q-Chem SF-TDA, 10 roots: mem_total 300000 (MB) set in the input, threads from qchem -nt; seed read by scf_guess read (not shipped).

Measurement notes

  • Q-Chem CPU load (CPU / wall from its output, 6-31G(d)): SCF 23-30 cores; response part TDA 1.4-1.9 cores, SF-TDA 1.1, MRSF-TDA 19.3. Q-Chem 6.4 runs in parallel only through OpenMP (qchem -nt 36; MPI only for finite-difference / many-body jobs, and this install has no MPI build): the TDA and SF-TDA response is effectively serial. def2-TZVP SF-TDA: 94 % of one core (top).
  • Psi4 memory: MEM_DF keeps the 3-index DF tensor in core (Psi4 output 'AOs need': 5.19 GiB 6-31G(d), 26.70 GiB def2-TZVP = (1260/552)^2 x); ORCA RIJCOSX stores no 3-index K tensor.
  • Psi4 has no ROKS ("ROHF reference for DFT is not available"): no Psi4 ROKS row. Psi4 UKS starts from the Psi4 UKS triplet seed, which reads the RKS seed (as in ORCA and Q-Chem).
  • Time split, every code: SCF, s + resp, s = Wall, s of the same run. SCF = the SCF time the code reports (ORCA 'SCF iterations' module timing, Q-Chem 'SCF time ... wall', Psi4 SI-SA-REKS: wall sum of the timers before 'REKS: compute_si'); resp = the rest of the run, start-up and output included. Psi4 SI: the run time outside the Psi4 timers falls into resp.
  • TO def2-TZVP: Q-Chem MRSF-TDA too slow: the same job in TC_tz took ~8 h for its first Davidson iteration; not run.
  • TO def2-TZVP: Q-Chem SF-TDA too slow: 7 Davidson iterations in 11 h on one core (94 % CPU), then stopped.
  • TO def2-TZVP: Q-Chem TDA too slow, not run: in 6-31G(d) TDA took as long as SF-TDA (1545 vs 1477 s), and SF-TDA here runs 10-11 h.
  • TC def2-TZVP: Q-Chem MRSF-TDA too slow: SCF 495 s, then the first Davidson iteration took ~8 h (6-31G(d): 10 iterations of ~540 s); stopped after 11.5 h.
  • TC def2-TZVP, Q-Chem TDA: stopped after ~30 min, no Davidson iteration completed.
  • † TC (10,10), TC def2-TZVP (8,8), (10,10): e 1e-7, d 1e-6; every other row e 1e-8, d 1e-7.

Mechanism

Integrals and the DFT quadrature grid are evaluated once; every configuration of the ensemble reads them. The Fock matrices of the configurations combine by weighted addition; energy and gradient of the ensemble follow from the assembled matrices.
