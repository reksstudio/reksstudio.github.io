16. Diagnose

Each entry names what the output prints, then what to do. A converged SCF can still show several of them.

SCF converges instantly to a wrong energy after a restart

The active-window orbitals of the loaded .wfn.npy landed in the wrong columns. Observed (linear H₄, BH&HLYP/6-31G, restart from a run with E = −1.88445354755929 Eh): the window ['HOMO-1', 'HOMO', 'LUMO+1', 'LUMO+2'] puts 5A into the active space and leaves 3A virtual; the setup lists Active MO indices 1A–4A, the FONs sit at 2 and 0, and the energy is 0.32 Eh higher:

GUESS READ: active window ['HOMO-1', 'HOMO', 'LUMO+1', 'LUMO+2'] -> MO columns [0, 1, 2, 3] (swaps [(2, 3), (3, 4)])
[...]
      Pairing scheme 0: (a,d) & (b,c) = (1A,5A) & (2A,4A)

       1A     -0.403994  (a)    n_a =  2.000000    m_a =  2.000000
       2A     -0.317491  (b)    n_b =  1.999750    m_b =  1.999273
       4A     -0.019252  (c)    n_c =  0.000250    m_c =  0.000727
       5A      0.753419  (d)    n_d =  0.000000    m_d =  0.000000

    Virtual (4):
[...]
       3A     -0.109675     6A      0.863523     7A      0.915719

@REKS Final Energy:    -1.56168292643458

Check the active set (Check the solution), also after a cold start (s-trans-butadiene REKS(4,4), cold SAD: setup 14A–17A, pairs (13A,17A) & (15A,16A)); for a REKS source, compare the final energy with that of the run that wrote the orbitals. Inspect the Molden file, then fix the window with GUESS_ACTIVE_WINDOW.

SCF hits MAXITER or continues unconverged

With the default FAIL_ON_MAXITER true the run stops with Failed to converge. and an SCFConvergenceError. With FAIL_ON_MAXITER false the trace ends as below (H₄, maxiter 2); SI, properties and files follow on the unconverged orbitals, and the wavefunction is returned.

 @REKS iter   2:    -1.88215688187835   -9.95203e-02   4.33488e-03 SHIFT
[...]
Energy and/or wave function did not converge, but proceeding anyway.

Save it with wfn.to_file(...) and restart from it rather than starting over (Restart mechanism). Raise MAXITER, or raise REKS_REPORT_LEVEL to 4 to see which GVB-DIIS monitor (verdict rewind, cycle detection, basin guard) fires repeatedly (§12).

SCF oscillates or cycles

The GVB-DIIS monitors (§12) catch and restart such runs. If that stays unproductive, use the REKS_USE_TRAH warm-up, or switch REKS_DIIS_FORMULATION between "ORBITAL" and "CFM".

FONs of a geminal invert

Post-Iterations prints np < nq for a geminal of generation ≥ 1 (generation-0 pairs are swapped, §11). Set a floor of 1.0 on its generation (REKS_<L>_FON).

FON pinned at a bound, symmetry-broken charges

Post-Iterations prints n_a = 2.000000, n_b = 0.000000, gradient() prints [GRAD-FON] … pinned, and equivalent atoms carry different charges. Example: 90° C₂H₄ from a cold SAD start; the RKS seed gives n 1/1 (Check the solution). On the cold branch (a separate BH&HLYP/6-31G run; Check the solution uses 6-31G(d)) the analytic S1 gradient agrees with a 5-point finite difference to 9·10−8 Eh/a0; a 2-point difference deviates by 2.3·10−2 because its −h point converges to the other solution.

Seed from an RKS run at the same geometry (Seed orbitals) or from a neighbouring geometry (Restart mechanism) and compare the FON columns between runs; geminals entering only SI configurations can also lie at the bound (FONs of the SI-only geminals). Optimizations: Check the optimization.

Active orbitals localize on one fragment

Set a positive REKS_DELOC_IPR_PENALTY; the report then ends with === REKS IPR Penalty Final === and the basin verdict.

Unknown configuration name or type

The error lists every valid type and name of the manifold the block is bound to, here REKS(4,4), 2S = 0; it is generated from the same catalog (§5):

Unknown REKS config token 'BOGUS'. Use the keyword 'full', 'sps', 'single-scheme[:N]', 'mixed-scheme[:N]', a name pattern with '*' or '?', a config type (PPS, OSS, DES, OSS_DES, DDES, DOSS_SPS), or a config name (PPS1, OSS1, OSS2, PPS2, OSS3, OSS4, DES1, DES2, DES3, DES4, OSS_DES1, OSS_DES2, OSS_DES3, OSS_DES4, DDES1, DDES2, DOSS_SPS_0, DOSS_SPS_1).

Active space fails to load

No catalog file exists for that active space; the error lists the installed ones (§5):

REKS active space [N=8, M=8] is not installed. Installed [N,M] active spaces: [2,2], [2,3](u=3), [2,4](u=4), [4,4], [4,5](u=23), [4,6](u=33), [6,6] (catalog directory …/share/psi4/reks_catalog; PSI4_REKS_CATALOG overrides it).

Ghost states and a collapsed SI spectrum

Observed (REKS(4,6)[3,3], H₄): Ghost states reports 159 removed roots, Independent states is 1, and S0 = −10358357.624062862247 Eh against E[SA-REKS] = −1.266834523295 Eh. Compare Independent states with Configurations and the null modes, and E(S0) with @REKS Final Energy (SI Hamiltonian and overlap).

Quasi-degenerate roots

SI_REKS_GRAD follows a root by index. The gap of the followed pair is printed in the NAC header (Nonadiabatic coupling vectors) and in the CI-topography header when it is below REKS_CI_TOPOGRAPHY_GAP (Conical-intersection topography); compare the leading configurations of the followed root in Adiabatic states between runs.
