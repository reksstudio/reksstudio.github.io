3. First Calculation

Without a seed the active slots are the MOs (Ncore+1)A … (Ncore+M)A (1-based labels) of the guess Fock matrix in energy order. A cold start of 90° C₂H₄ converges to n = 2/0, of s-trans-butadiene to a pair with a σ orbital (Check the solution). Procedure: choose the pairs → seed → inspect → start REKS → check.

Which active space?

A rhetorical question: no rule fixes it for every molecule. REKS reduces it to whole pairs. In CASSCF the active orbitals and electrons are chosen one by one, e.g. the full π system; a REKS active space is a set of pairs, each the bonding and antibonding orbital of one bond that breaks, twists or is excited, and it grows or shrinks by one pair.

Choose the pairs

Each pair of REKS(M,M) (Pairing scheme) is a bonding orbital and its antibonding partner.

Molecule Active space Pairs
C₂H₄, 90° twist (2,2) (π, π*): in-phase and out-of-phase combination of the two C 2p orbitals of the twisted bond
s-trans-butadiene (4,4) (π₁, π₄*) & (π₂, π₃*)
all-trans-hexatriene (6,6) (π₁, π₆*) & (π₂, π₅*) & (π₃, π₄*)

Scheme 0 (Pairing scheme) sets the token order of a window: the bonding orbitals first, their partners in reverse order:

[φ1,…,φP, φP∗,…,φ1∗]

Seed orbitals

A closed-shell RKS run with the functional and basis of the REKS run, scf_type stated, writes the seed and a Molden file:

psi4.set_options({"basis": "6-31g(d)", "scf_type": "pk", "molden_write": True})
e, wfn = psi4.energy("bhhlyp", return_wfn=True)
wfn.to_file("first_c2h4_90_rks.wfn")          # first_c2h4_90_rks.wfn.npy

Check the seed: the frontier orbitals are spread equally over symmetry-equivalent atoms. Mulliken population of MO i on atom A, qA(i)=∑μ∈ACμi(𝐒𝐂)μi:

C, S, bs = wfn.Ca().np, wfn.S().np, wfn.basisset()
i = wfn.nalpha() - 1                                   # HOMO; i + 1 is LUMO
q = C[:, i] * (S @ C[:, i])
print([q[[mu for mu in range(bs.nbf()) if bs.function_to_center(mu) == A]].sum() for A in (0, 1)])

The seeds on this page use scf_type pk. A localized seed is replaced by an RKS run with scf_type pk or by a seed from a smaller torsion, carried to the target geometry (Scans). An ROHF triplet seed of 90° C₂H₄ gives the cold-start solution (n 2.000000 / 0.000000, ESA −78.353499 Eh).

Inspect the orbitals

Open the RKS Molden file in a viewer, name the M orbitals by character and note their 0-based columns: MO kA is column k − 1. Without a viewer, the population snippet above with the sum over the AO functions of one type (e.g. the p functions normal to a molecular plane for π) separates σ from π.

Diffuse basis
the valence antibonding orbital can lie far above LUMO; give its column as an integer token. Butadiene, aug-cc-pVDZ: LUMO is π₃*, LUMO+1 … LUMO+5 are σ, the largest π₄* component is LUMO+6 (column 21); ["HOMO-1", "HOMO", "LUMO", 21] prints swaps [(16, 21)].
Degenerate orbitals
π of a linear molecule. The rotation within a degenerate RKS pair is arbitrary between runs, and the REKS result follows it. N₂ 1.60 Å, REKS(6,6), one window ['HOMO-2', 'HOMO-1', 'HOMO', 'LUMO+1', 'LUMO', 'LUMO+2'], three RKS seeds: π FON 1.651544, 1.703717, 1.999994.

Start REKS

psi4.set_options({"basis": "6-31g(d)", "scf_type": "pk",      # as in the seed run
                  "reference": "reks", "reks": [4, 4],
                  "guess_active_window": ["HOMO-1", "HOMO", "LUMO", "LUMO+1"]})
e_sa, wfn = psi4.energy("bhhlyp", return_wfn=True, restart_file="first_butadiene_rks.wfn.npy")

The seed run above, for butadiene, writes first_butadiene_rks.wfn (Worked inputs).

Seed
restart_file sets GUESS READ (Restart mechanism); an RKS source is reported as SCF Guess: REKS orbitals restored from previous computation (REKS::guess override).
Slots
token k = 0 … M−1 fills active column Ncore + k (0-based columns, Inspect the orbitals); token order sets the pairs (Choose the pairs). Without a window the slots are the read columns Ncore … Ncore+M−1 (C₂H₄ above: HOMO, LUMO).
Report
MO columns lists the active columns; swaps [(c, j)]: MO j moved into active column c (GUESS_ACTIVE_WINDOW).

Check the solution

Convergence
Energy and wave function converged. is necessary only: every wrong solution on this page converged. Otherwise SCF hits MAXITER or continues unconverged.
Active set
every index of Pairing scheme 0 in Post-Iterations (Fractional occupation numbers of the SA-REKS ensemble) belongs to the inspected set, compared as a set: setup 8A(a), 9A(b), pair printed (9A,8A) (generation-0 swap, §11). Otherwise SCF converges instantly to a wrong energy after a restart.
Symmetry
S0 has equal charges on symmetry-equivalent atoms (Atomic charges of the states (unrelaxed)) and a dipole allowed by the point group (Permanent and difference dipole moments (unrelaxed)). Otherwise FON pinned at a bound, symmetry-broken charges.
FONs
a pair at n ≈ 2/0 is not by itself an error: the outer π pair of butadiene has na = 1.999999.

Higher spin states

A state of spin S > 0 needs no SCF of its own: it is a root of an SI cassette on manifold 2S, built in the converged SA orbitals (Spin manifold and run sector). REKS(M,M) holds the manifolds 2S = 0, 2, …, M; a configuration of 2S = 2k carries k triplet geminals, prefixes T_, TT_, TTT_. One full cassette per manifold:

"si_reks_configs": [[["full"]], [["full"]], [["full"]], [["full"]]],
"si_reks_2spin": [0, 2, 4, 6],

    Spins = the two spin multiplicities compared (S/T = singlet/triplet). Low-/high-spin state = lowest state of each multiplicity over all cassettes.
    Gap = E(high spin) - E(low spin). Lowering(lo/hi) = SI lowering of that state, min_i H_ii - E.
    J = -Gap/(2 S_high), for H = -2J S_A.S_B. J is a spin-coupling constant only if
    the two states have the same open-shell orbitals and similar SI lowering.
    Q = quintet (not quartet), Sp = septet.

J is a coupling constant only for two states with the same open-shell orbitals; T1 (c,d) and Q1 (b,e)(c,d) differ.

Scans

Anchor
converge and check one point (Check the solution); every further point reads the REKS wavefunction of the previous one (Restart mechanism). 90° C₂H₄ seeded by RKS at 60°, then 60° → 75° → 90°: na 1.942502, 1.637928, 1.000000. Optimizations and trajectories chain the points in the same way (§4).
Basis
converge in the small basis, then read into the large one. BASIS_GUESS stops a REKS run: BASIS_GUESS is not available with REKS. Converge REKS in the smaller basis and read its orbitals (GUESS READ / restart_file): they are projected onto the target basis pair by pair. 90° C₂H₄, 6-31G(d) REKS file read into cc-pVTZ: Computing basis projection from 6-31G(D) to CC-PVTZ, n 1.000000 / 1.000000, ESA = −78.402409150180 Eh.

If the SCF does not converge

Inspect the window first (Inspect the orbitals), then The three engines, SCF hits MAXITER or continues unconverged, SCF oscillates or cycles.
