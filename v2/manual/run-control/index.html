8. Guesses and Restarts

Restarts use Psi4 checkpoints; GUESS_ACTIVE_WINDOW places the read orbitals in the active space. Seeding a first calculation: §3.

Restart mechanism

E, wfn = psi4.energy("bhhlyp", restart_file="name.wfn.npy", return_wfn=True)   # read a checkpoint
wfn.to_file("name.wfn")                                                          # writes name.wfn.npy
  • restart_file names a serialized Wavefunction (.wfn.npy). For a .npy file the driver sets GUESS READ and prints Found user provided orbital data. Setting orbital guess to READ. psi4.core.Wavefunction.from_file(...) only loads the file into a Python object; the SCF guess does not use it.
  • "df_scf_guess" acts only with scf_type DIRECT, where it runs a density-fitted SCF before the exact-integral SCF.
  • Restart points: the previous geometry of a scan, a lower-level pre-optimization, a run that hit maxiter (SCF hits MAXITER or continues unconverged), or an RKS run at the same geometry (Seed orbitals).

A scan restarts each point from the previous one; psi4.core.clean() removes the scratch files of the finished point:

psi4.set_options({"basis": "6-31g", "scf_type": "pk", "reference": "reks", "reks": [4, 4]})
restart = {}
for r in (1.4, 1.5, 1.6):
    psi4.geometry(f"H 0 0 0\nH 0 0 {r}\nH 0 0 {2 * r}\nH 0 0 {3 * r}\nsymmetry c1")
    e, wfn = psi4.energy("bhhlyp", return_wfn=True, **restart)
    wfn.to_file(f"h4_{r}.wfn")
    restart = {"restart_file": f"h4_{r}.wfn.npy"}
    psi4.core.clean()

Linear H₄, BH&HLYP/6-31G: the restarted point 1.6 Å and a cold SAD start reach the same E = −1.884453547559 Eh.

Pre-Iterations reports the guess. A REKS restart file restores the orbitals and the FON sets of the run that wrote it; the REKS orbitals line is printed at every level:

==> Pre-Iterations <==

SCF Guess: REKS orbitals restored from previous computation (REKS::guess override).

    FON sets restored from the saved wavefunction:
    n: n_a = 1.970714, n_b = 1.390406;
    m: m_a = 1.970145, m_b = 1.389772.
[...]
  REKS orbitals: core 6 / active 4 (4 electrons) / virtual 28

MOLDEN_WRITE (standard Psi4) writes the final orbitals to a Molden file for inspection of the active window (Files).

GUESS_ACTIVE_WINDOW

Type
array
Default
[] (off)
"guess_active_window": ["HOMO-1", "HOMO", "LUMO", "LUMO+1"],
  • Moves the listed MOs of the read guess into the active MO columns by column swaps, one token per active orbital, in active-column order; a displaced MO takes the vacated column. Token order sets the pairs (Pairing scheme, Choose the pairs). The call above is for reks [4, 4].
  • Tokens: 0-based MO indices or HOMO, LUMO, HOMO-k, LUMO+k of the loaded α occupation. The GUESS READ: active window line reports the resolved columns and swaps (SCF converges instantly to a wrong energy after a restart).
  • Requires guess read (a REKS run stops with a ValidationError otherwise); a non-REKS reference ignores the option. C1 only.
  • If projection onto the current basis drops a read MO as linearly dependent, REKS READ: WARNING names it; the later columns shift, and the window may no longer match.

9. Fractional Occupation Numbers (FONs)

Each geminal pair carries FONs with np+nq=2; the free FON np (first orbital of the pair) lies in a box (§2):

np∈[ℓ,2−m],ℓ={𝚁𝙴𝙺𝚂_<𝙻>_𝙵𝙾𝙽if≥0motherwise,m=𝚁𝙴𝙺𝚂_𝙵𝙾𝙽_𝙼𝙸𝙲𝚁𝙾_𝙱𝙾𝚄𝙽𝙳_𝙼𝙰𝚁𝙶𝙸𝙽.

A generation-0 FON of a two-orbital pair that crosses 1 swaps the two orbitals, so the printed generation-0 FONs have np≥nq; FONs of higher generations can have np<nq. FONs are optimized every SCF iteration by a projected-Newton micro-solver with Armijo backtracking: one joint Newton solve over all FONs of a (sector, generation) block, the other blocks held fixed. FONs are stored per FON set (§4); each generation has its own lower-bound option, default -1.0 (off):

Generation (set) 0 (n) 1 (m) 2 (u) 3 (v) 4 (w) 5 (x) 6 (y) 7 (z)
Option REKS_N_FON REKS_M_FON REKS_U_FON REKS_V_FON REKS_W_FON REKS_X_FON REKS_Y_FON REKS_Z_FON

REKS_<L>_FON

Type
double
Default
-1.0 each
"reks_m_fon": 1.0,
[REKS] REKS_M_FON lower bound = 1.00000000 (experimental limiter active)
[REKS] WARNING: REKS_M_FON=2.50000000 exceeds maximum valid floor 1.99999999; clamped (FON frozen at upper boundary).
  • One option per FON generation (table above). A non-negative value ℓ is the lower end of the box of the free FON np of every geminal of that generation (§9): np stays variable in [ℓ, 2 − m], m = REKS_FON_MICRO_BOUND_MARGIN.
  • The call above restricts np of every generation-1 geminal to [1, 2 − m]: it excludes np < nq, and np may still reach the closed-shell limit 2 (FONs of a geminal invert). At REKS_REPORT_LEVEL ≥ 4 an active floor prints the first line above.
  • A value above 2 − m is clamped to 2 − m and the FON is frozen there, with the warning above (REKS_M_FON 2.5). Negative (the default) disables the bound; the lower end is then m.

FON micro-solver traces are printed at REKS_REPORT_LEVEL ≥ 4.

10. SCF Convergence Engines

Three engines optimize the orbitals and FONs; most runs set at most LEVEL_SHIFT and REKS_USE_TRAH.

The three engines

REKS_USE_TRAH REKS_GVB_DIIS Iterations (trace tag)
false (default) true (default) the first REKS_GVB_DIIS_START − 1 iterations are level-shifted Fock steps without an accelerator (SHIFT), then GVB-DIIS
true true TRAH warm-up (TRAH/SHIFT); GVB-DIIS once REKS_GVB_DIIS_START is reached and the active formulation's activation gate is satisfied
true false TRAH for the entire SCF
false false level-shifted Fock steps (PLAIN/SHIFT)

Iterations prints one line per SCF iteration: @REKS iter (@DF-REKS iter with density fitting), the SA-REKS energy, its change, RMS |[F,D]| and the engine tag. RMS |[F,D]| is compared with D_CONVERGENCE; with n the number of MOs it is

RMS={‖𝐠orb‖F/nGVB-DIISmax⁡(‖𝐠orb‖2+‖𝐠FON‖2, ‖𝐕−𝟏‖F)/nTRAHrms(𝐅𝐃𝐒−𝐒𝐃𝐅)otherwise

with 𝐠orb, 𝐠FON the orbital and FON gradients and 𝐕 the rotation that canonicalizes the current orbitals within their roles. GVB-DIIS converges when |ΔE|< E_CONVERGENCE and RMS < D_CONVERGENCE hold in REKS_GVB_GATE_STREAK (default 2) consecutive iterations; the sign of ΔE is not tested, so the last iterations may rise within these bounds. A converged SCF ends with the line below (otherwise SCF hits MAXITER or continues unconverged):

 @DF-REKS iter   3:    -1.85801940076408   -1.86565e-03   6.51017e-03 ORB-GVB-DIIS
[...]
 @DF-REKS iter  11:    -1.85941446727766   -2.22045e-16   8.69069e-11 ORB-GVB-DIIS

REKS_USE_TRAH

Type
bool
Default
false
"reks_use_trah": True,
  • Trust-region Newton solver (trace tag TRAH/SHIFT) for the stationary point of the SA energy in the active–active orbital rotations and the FONs: a box-constrained damped Newton step from the eigendecomposition of the analytic active–active Hessian, a bisection on the damping until the step norm matches the trust radius, and eigenvector following along the inter-pair modes (Nocedal & Wright Ch. 4 and 11; Baker 1986; Cerjan & Miller 1981; Helmich-Paris 2021; §16).
  • Warm-up or whole SCF: table above.

REKS_GVB_DIIS

Type
bool
Default
true
"reks_gvb_diis": False,
  • The GVB-DIIS accelerator, the default engine; its formulation is REKS_DIIS_FORMULATION.

REKS_DIIS_FORMULATION

Type
CFM|ORBITAL
Default
ORBITAL
"reks_diis_formulation": "CFM",
  • ORBITAL (default; trace tag ORB-GVB-DIIS) extrapolates skew-symmetric rotation generators κ directly in the MO basis and bypasses Fock diagonalization each step (Ionova & Carter 1995; the r-GDIIS variant of Sethio et al. 2024).
  • CFM (trace tag CFM-GVB-DIIS/SHIFT) extrapolates the composite multishell Fock matrix, the multishell-Fock DIIS of Muller et al. 1994, where every active orbital is its own shell (core = 1 shell, virtual = 1 shell).

Type
double

1.0 (CFM only)
"reks_gvb_level_shift": 1.0,
  • Artificial shell gap of the CFM multishell Fock matrix, separate from LEVEL_SHIFT; unused with REKS_DIIS_FORMULATION ORBITAL (the default).

Level shift

REKS reads Psi4's LEVEL_SHIFT / LEVEL_SHIFT_CUTOFF; when unset, REKS sets LEVEL_SHIFT = 0.6 and LEVEL_SHIFT_CUTOFF = 0.0 (the shift stays on for the whole SCF). The shift acts on the Fock-diagonalization steps (trace tags ending in SHIFT); ORB-GVB-DIIS steps diagonalize no Fock matrix and carry no shift. It is a staircase over the active slots k=0,1,… (ordered within each geminal by the diagonal Fock elements) and the virtuals, with base shift s:

Δεk=(k+1)s,Δεvirt=(nact+1)s.

LEVEL_SHIFT_ADAPT

Type
bool
Default
true
"level_shift_adapt": False,
  • True: the base shift equals LEVEL_SHIFT through iteration 3; afterwards it decays (factor 0.5–0.95) when the previous iteration had no orbital swaps and maximal active mixing below 0.15, and grows by a factor 1.5 when the previous iteration had swaps or mixing above 0.30; it stays within [0.01, LEVEL_SHIFT].
  • False holds the base shift at LEVEL_SHIFT for every iteration.

Expert stabilizers

The two expert groups of §15 (angle filtering, SVD conditioning, Tikhonov ridging, verdict rewind and restart monitors, cycle detection, basin guards) act automatically on ill-conditioned or non-monotone GVB-DIIS steps. REKS_REPORT_LEVEL 4 shows which monitor fires.

REKS_DELOC_IPR_PENALTY

Type
double
Default
0.0 (off)
"reks_deloc_ipr_penalty": 0.05,
=== REKS IPR Penalty Final ===
[IPR] final: IPR_total=1.1017  (can_ref=1.000, loc_ref=2.000)
[IPR] final: E_pen=5.508254e-02 Ha (lambda=5.000e-02)

  • Epen is added to the SA energy; pA(i) is the population of active MO i on atom A, and ΣA pA(i)2 = 1 for an orbital on one atom. λ is in Eh; λ < 0 is an input error.
  • λ > 0 penalizes localization of the active orbitals and drives the SCF to the delocalized solution, the intended REKS solution. Linear H4 (1.6 Å), BH&HLYP/6-31G, REKS(4,4): IPR_total 1.1128 at λ = 0 and 1.0669 at λ = 0.05.

13. Diagnose

Each entry names what the output prints, then what to do. A converged SCF can still show several of them.

SCF converges instantly to a wrong energy after a restart

The active-window orbitals of the loaded .wfn.npy landed in the wrong columns. Observed (linear H₄, BH&HLYP/6-31G, restart from a run with E = −1.88445354755929 Eh): the window ['HOMO-1', 'HOMO', 'LUMO+1', 'LUMO+2'] puts 5A into the active space and leaves 3A virtual; the setup lists Active MO indices 1A–4A, the FONs sit at 2 and 0, and the energy is 0.32 Eh higher:

Inspect the Molden file, then fix the window with GUESS_ACTIVE_WINDOW.

SCF hits MAXITER or continues unconverged

With FAIL_ON_MAXITER false the trace ends as below (H₄, maxiter 2); SI, properties and files follow on the unconverged orbitals, and the wavefunction is returned.

 @REKS iter   2:    -1.88215688187835   -9.95203e-02   4.33488e-03 SHIFT
[...]
Energy and/or wave function did not converge, but proceeding anyway.

Save it with wfn.to_file(...) and restart from it rather than starting over (Restart mechanism). Raise MAXITER, or raise REKS_REPORT_LEVEL to 4 to see which GVB-DIIS monitor (verdict rewind, cycle detection, basin guard) fires repeatedly (§10).

SCF oscillates or cycles

The GVB-DIIS monitors (§10) catch and restart such runs. If that stays unproductive, use the REKS_USE_TRAH warm-up, or switch REKS_DIIS_FORMULATION between "ORBITAL" and "CFM".

FONs of a geminal invert

Post-Iterations prints np < nq for a geminal of generation ≥ 1 (generation-0 pairs are swapped, §9). A floor of 1.0 on its generation (REKS_<L>_FON; e.g. reks_m_fon: 1.0 for generation m) excludes np < nq without fixing the FON to a single value. The floor does not keep np away from the closed-shell limit 2.

FON pinned at a bound, symmetry-broken charges

Post-Iterations prints n_a = 2.000000, n_b = 0.000000, and equivalent atoms carry different charges. Observed: twisted ethylene (90°), SSR(2,2), BH&HLYP/6-31G, cold SAD start; seeded from 60° and 75°, the same geometry converges to n_a = 1.000000 with C1 = C2 = −0.334991 (S0). On the cold branch the analytic S1 gradient agrees with a 5-point finite difference to 9·10−8 Eh/a0; a 2-point difference deviates by 2.3·10−2 because its −h point converges to the other solution.

Seed from an RKS run at the same geometry (Seed orbitals) or from a neighbouring geometry (Restart mechanism) and compare the FON columns between runs; geminals entering only SI configurations can also lie at the bound (FONs of the SI-only geminals).

Active orbitals localize on one fragment

The active orbitals localize instead of forming the delocalized solution, the intended REKS solution. Set a positive REKS_DELOC_IPR_PENALTY; the report then ends with === REKS IPR Penalty Final === and the basin verdict.

Unknown configuration name or type

The error lists every valid type and name of the manifold the block is bound to, here REKS(4,4), 2S = 0; it is generated from the same catalog (§4):

Unknown REKS config token 'BOGUS'. Use the keyword 'full', 'sps', 'single-scheme[:N]', 'mixed-scheme[:N]', a name pattern with '*' or '?', a config type (PPS, OSS, DES, OSS_DES, DDES, DOSS_SPS), or a config name (PPS1, OSS1, OSS2, PPS2, OSS3, OSS4, DES1, DES2, DES3, DES4, OSS_DES1, OSS_DES2, OSS_DES3, OSS_DES4, DDES1, DDES2, DOSS_SPS_0, DOSS_SPS_1).

Active space fails to load

No catalog file exists for that active space; the error lists the installed ones (§4):

REKS active space [N=8, M=8] is not installed. Installed [N,M] active spaces: [2,2], [2,3](u=3), [2,4](u=4), [4,4], [4,5](u=23), [4,6](u=33), [6,6] (catalog directory …/share/psi4/reks_catalog; PSI4_REKS_CATALOG overrides it).

Ghost states and a collapsed SI spectrum

Observed (REKS(4,6)[3,3], H₄): Ghost states reports 159 removed states, Independent states is 1, and S0 = −10358357.624062862247 Eh against E[SA-REKS] = −1.266834523295 Eh. Compare Independent states with Configurations and the null modes, and E(S0) with @REKS Final Energy (SI Hamiltonian and overlap).

Quasi-degenerate roots

SI_REKS_GRAD follows a root by index. The gap of the followed pair is printed in the NAC header (Nonadiabatic coupling vectors) and in the CI-topography header when it is below REKS_CI_TOPOGRAPHY_GAP (Conical-intersection topography); compare the leading configurations of the followed root in Adiabatic states between runs.
