10. Guesses and Restarts

Restarts use Psi4 checkpoints; GUESS_ACTIVE_WINDOW places the read orbitals in the active space. Seeding a first calculation: §3.

Restart mechanism

E, wfn = psi4.energy("bhhlyp", restart_file="name.wfn.npy", return_wfn=True)   # read a checkpoint
wfn.to_file("name.wfn")                                                          # writes name.wfn.npy
  • restart_file names a serialized Wavefunction (.wfn.npy). For a .npy file the driver sets GUESS READ and prints Found user provided orbital data. Setting orbital guess to READ. psi4.core.Wavefunction.from_file(...) only loads the file into a Python object; the SCF guess does not use it.
  • A restart_file that names no file stops the run before the SCF with FileNotFoundError: energy() with Psi4's No such file or directory, gradient(), optimize() and hessian() with the path looked for and the current directory. These three read only .npy files; an existing file of another type, or an item that is not a path, is a ValidationError. A relative path is taken from the current directory at the moment of the call (an absolute path for drivers that change directory, Worked inputs).
  • "df_scf_guess" acts only with scf_type DIRECT, where it runs a density-fitted SCF before the exact-integral SCF.
  • Restart points: the previous geometry of a scan, a lower-level pre-optimization, a run that hit maxiter (SCF hits MAXITER or continues unconverged), or an RKS run at the same geometry (Seed orbitals).

A scan (Scans) in code; psi4.core.clean() removes the scratch files of the finished point:

psi4.set_options({"basis": "6-31g", "scf_type": "pk", "reference": "reks", "reks": [4, 4]})
restart = {}
for r in (1.4, 1.5, 1.6):
    psi4.geometry(f"H 0 0 0\nH 0 0 {r}\nH 0 0 {2 * r}\nH 0 0 {3 * r}\nsymmetry c1")
    e, wfn = psi4.energy("bhhlyp", return_wfn=True, **restart)
    wfn.to_file(f"h4_{r}.wfn")
    restart = {"restart_file": f"h4_{r}.wfn.npy"}
    psi4.core.clean()

Linear H₄, BH&HLYP/6-31G: the restarted point 1.6 Å and a cold SAD start reach the same E = −1.884453547559 Eh.

MOLDEN_WRITE (standard Psi4) writes the final orbitals to a Molden file for inspection of the active window (Files).

GUESS_ACTIVE_WINDOW

MOs of the read guess placed in the active columns, one token per active orbital: 0-based index, HOMO-k or LUMO+k.

Type
array
Default
[] (off)
"guess_active_window": ["HOMO-1", "HOMO", "LUMO", "LUMO+1"],
  • Moves the listed MOs of the read guess into the active MO columns by column swaps, one token per active orbital, in active-column order; a displaced MO takes the vacated column. Token order sets the pairs (Pairing scheme, Choose the pairs). The call above is for reks [4, 4].
  • Tokens: 0-based MO indices or HOMO, LUMO, HOMO-k, LUMO+k of the loaded α occupation. The GUESS READ: active window line reports the resolved columns and swaps (SCF converges instantly to a wrong energy after a restart).
  • Requires guess read (a REKS run stops with a ValidationError otherwise); a non-REKS reference ignores the option. C1 only.
  • If projection onto the current basis drops a read MO as linearly dependent, REKS READ: WARNING names it; the later columns shift, and the window may no longer match.

11. Fractional Occupation Numbers (FONs)

Each geminal pair carries FONs with np+nq=2 (Geminals); the free FON np (first orbital of the pair) lies in a box, kept by the FON micro-solver and the TRAH step (FONs restored from a REKS restart file are clamped to [m,2−m]):

np∈[ℓ,2−m],ℓ={𝚁𝙴𝙺𝚂_<𝙻>_𝙵𝙾𝙽if≥0motherwise,m=𝚁𝙴𝙺𝚂_𝙵𝙾𝙽_𝙼𝙸𝙲𝚁𝙾_𝙱𝙾𝚄𝙽𝙳_𝙼𝙰𝚁𝙶𝙸𝙽.

A FON pushed past an end of the box stops on it, and the SCF counts it converged there. Generation-0 geminals are kept in descending occupation by reordering their orbitals, columns and FONs of every set together (the energy is unchanged): the first FON step orders each geminal, later a two-orbital pair whose FON crosses 1 swaps its orbitals and a wider geminal is reordered when its order changes. Without REKS_USE_TRAH the printed generation-0 FONs therefore have np≥nq, with one exception: in an SA ensemble over several spin sectors a pair swaps when its FON crosses 1 in any sector, which can leave the printed FON below 1. TRAH steps move the FONs without reordering. FONs of higher generations are never reordered and can have np<nq. Outside TRAH steps FONs are optimized every SCF iteration by a projected-Newton micro-solver with Armijo backtracking: one joint Newton solve over all FONs of a (sector, generation) block, the other blocks held fixed. FONs are stored per FON set; each generation has its own lower-bound option (REKS_<L>_FON).

REKS_<L>_FON

Lower bound on the free FON n_p of every geminal of one FON generation (reks_n_fon, reks_m_fon, …); negative disables it.

Type
double
Default
-1.0 each
"reks_m_fon": 1.0,
[REKS] REKS_M_FON lower bound = 1.00000000 (experimental limiter active)
[REKS] WARNING: REKS_M_FON=2.50000000 exceeds maximum valid floor 1.99999999; clamped (FON frozen at upper boundary).
  • One option per FON generation (FON sets). A non-negative value ℓ is the lower end of the box of the free FON np of every geminal of that generation (§11): np stays variable in [ℓ, 2 − m], m = REKS_FON_MICRO_BOUND_MARGIN.
  • The call above restricts np of every generation-1 geminal to [1, 2 − m]: it excludes np < nq, and np may still reach the closed-shell limit 2 (FONs of a geminal invert). At REKS_REPORT_LEVEL ≥ 4 an active floor prints the first line above.
  • A value above 2 − m is clamped to 2 − m and the FON is frozen there, with the warning above (REKS_M_FON 2.5). Negative (the default) disables the bound; the lower end is then m.

FON micro-solver traces are printed at REKS_REPORT_LEVEL ≥ 4.

12. SCF Convergence Engines

Three engines optimize the orbitals and FONs; most runs set at most LEVEL_SHIFT and REKS_USE_TRAH.

The three engines

REKS_USE_TRAH REKS_GVB_DIIS Iterations (trace tag)
false (default) true (default) the first REKS_GVB_DIIS_START − 1 iterations are level-shifted Fock steps without an accelerator (SHIFT), then GVB-DIIS
true true TRAH warm-up (TRAH/SHIFT); GVB-DIIS from iteration REKS_GVB_DIIS_START, with CFM, and with ORBITAL under REKS_DIIS_ACTIVATION GRADIENT, once ‖gorb‖F < REKS_DIIS_CFM_ACTIVATION_GORB
true false TRAH for the entire SCF
false false level-shifted Fock steps (PLAIN/SHIFT)

Iterations prints one line per SCF iteration: @REKS iter (@DF-REKS iter with density fitting), the SA-REKS energy, its change, RMS |[F,D]| and the engine tag. RMS |[F,D]| is compared with D_CONVERGENCE; with n the number of MOs it is

RMS={‖𝐠orb‖F/nGVB-DIISmax⁡(‖𝐠orb‖2+‖𝐠FON‖2, ‖𝐕−𝟏‖F)/nTRAHrms(𝐅𝐃𝐒−𝐒𝐃𝐅)otherwise

with 𝐠orb, 𝐠FON the orbital and FON gradients and 𝐕 the rotation that canonicalizes the current orbitals within their roles. GVB-DIIS converges when |ΔE|< E_CONVERGENCE and RMS < D_CONVERGENCE hold in REKS_GVB_GATE_STREAK (default 2) consecutive iterations; the sign of ΔE is not tested, so the last iterations may rise within these bounds. REKS_USE_TRAH

Trust-region Newton (TRAH) step on the active–active rotations and FONs: warm-up before GVB-DIIS, or the whole SCF without it.

Type
bool
Default
false
"reks_use_trah": True,
  • Trust-region Newton solver (trace tag TRAH/SHIFT) for the stationary point of the SA energy in the active–active orbital rotations and the FONs: a box-constrained damped Newton step from the eigendecomposition of the analytic active–active Hessian, a bisection on the damping until the step norm matches the trust radius, and eigenvector following along the inter-pair modes (Nocedal and Wright, Numerical Optimization 2006, Ch. 4 and 11; Baker, J. Comput. Chem. 1986, 7, 385; Cerjan and Miller, J. Chem. Phys. 1981, 75, 2800; Helmich-Paris, J. Chem. Phys. 2021, 154, 164104).
  • The intra-geminal rotations and the FONs are minimized; their Hessian block enters the step with |λ| of its eigenvalues. When that block has a negative eigenvalue λ (eigenvector v) and ½ |λ| Δ2 > E_CONVERGENCE (Δ the trust radius), the step s is extended along v to the trust radius, s → s + σ τ v with τ = (Δ2 − ‖s‖2)½ cut back to the variable bounds and σ = −sign(g · v); such a point is left, not reported as converged. After this step the trust radius follows the energy ratio ρ = ΔE / ΔEmodel.
  • TRAH steps move the FONs without reordering the orbitals of a geminal (§11).
  • Warm-up or whole SCF: The three engines.

REKS_DIIS_FORMULATION

GVB-DIIS formulation: extrapolation of the orbital-rotation generators κ, or of the composite multishell Fock matrix (CFM).

Type

Default

"reks_diis_formulation": "CFM",
  • ORBITAL (default; trace tag ORB-GVB-DIIS) extrapolates skew-symmetric rotation generators κ directly in the MO basis and bypasses Fock diagonalization each step (Ionova and Carter, J. Chem. Phys. 1995, 102, 1251; the r-GDIIS variant of Sethio et al., J. Phys. Chem. A 2024, 128, 2472).
  • CFM (trace tag CFM-GVB-DIIS/SHIFT) extrapolates the composite multishell Fock matrix, the multishell-Fock DIIS of Muller et al., J. Chem. Phys. 1994, 100, 1226, where every active orbital is its own shell (core = 1 shell, virtual = 1 shell).

Level shift

REKS reads Psi4's LEVEL_SHIFT / LEVEL_SHIFT_CUTOFF; when unset, REKS sets LEVEL_SHIFT = 0.6 and LEVEL_SHIFT_CUTOFF = 0.0 (the shift stays on for the whole SCF). The shift acts on the Fock-diagonalization steps (trace tags ending in SHIFT); ORB-GVB-DIIS steps diagonalize no Fock matrix and carry no shift. It is a staircase over the active slots k=0,1,… (ordered within each geminal by the diagonal Fock elements) and the virtuals, with base shift s:

Δεk=(k+1)s,Δεvirt=(nact+1)s.

LEVEL_SHIFT_ADAPT

Adaptive base of the staircase level shift: decays while the orbitals are stable, grows back up to level_shift on swaps or strong mixing.

Type
bool
Default
true
"level_shift_adapt": False,
  • True: the base shift equals LEVEL_SHIFT through iteration 3; afterwards it decays (factor 0.5–0.95) when the previous iteration had no orbital swaps and maximal active mixing below 0.15, and grows by a factor 1.5 when the previous iteration had swaps or mixing above 0.30; it stays within [0.01, LEVEL_SHIFT].
  • False holds the base shift at LEVEL_SHIFT for every iteration.

Expert stabilizers

The two expert groups of §17 (angle filtering, SVD conditioning, Tikhonov ridging, verdict rewind and restart monitors, cycle detection, basin guards) act automatically on ill-conditioned or non-monotone GVB-DIIS steps. REKS_REPORT_LEVEL 4 shows which monitor fires.

GVB-DIIS keeps the last DIIS_MAX_VECS (default 10) error vectors; a new vector replaces the oldest. The angle filter (REKS_DIIS_COND_ANGLE_FILTER) keeps the newest vector 𝐞0 and tests the others from newer to older on their differences 𝐝i=𝐞i−𝐞0; vector i is dropped when

δ‖𝐞i‖2≥‖𝐞0‖2,cmax⁡‖𝐝i‖2≤‖𝐞0‖2,orsin⁡φi=‖(𝟏−𝐏)𝐝i‖‖𝐝i‖<cs,

with 𝐏 the projector on the differences kept so far, δ = REKS_DIIS_COND_STALE_DELTA, cmax⁡ = REKS_DIIS_COND_COEFF_NORM_MAX, cs = REKS_DIIS_COND_ANGLE_CUTOFF.

13. Geminal Delocalization

REKS_GEMINAL_DELOC rotates each orbital pair of a generation-0 geminal whose Löwdin IPR lies in the upper half of its range under rotations of the pair to the IPR minimum (the most delocalized frame of the pair), converges the SCF again from the rotated orbitals, and keeps the rotated solution only if its ESA is lower.

REKS_GEMINAL_DELOC

After the SCF, rotates generation-0 geminal pairs to their IPR minimum and reconverges; kept if it converges to a lower E_SA.

Type
bool
Default
false
"reks_geminal_deloc": True,

  x: position of the pair's Loewdin frame between the minimum (0) and the maximum (1) of
     IPR_ab = sum_A [p_a(A)^2 + p_b(A)^2] over rotations of the pair; rotated to the minimum

  E_SA before rotation       -78.351265591745
  E_SA after rotation        -78.362111811377

==> REKS Geminal Delocalization <==

  E_SA before rotation       -77.884884825216
  E_SA after rotation        -77.884884825216
  Rotated solution rejected; SCF restarts from the orbitals before the rotation.
  • After the SCF converges, every orbital pair (a, b) of every generation-0 geminal is tested: IPRab, the Löwdin inverse participation ratio of the pair, runs over [IPRab(0) + α − r, IPRab(0) + α + r] under the rotation θ, and x is the position of the current orbitals in that range (0 = minimum, 1 = maximum). A pair with x > 1/2 is rotated by θ* to the minimum; a pair with r ≤ 64 ε IPRab(0) (ε the machine epsilon) is left alone. Sweeps over all pairs repeat until one rotates nothing; the FONs are not changed.
  • First block: the rotated pairs (geminal, 1-based MO numbers, x, θ* in degrees); the SCF then converges again from the rotated orbitals. Without a pair at x > 1/2 the block reads No geminal orbital pair with x > 1/2. and no further SCF runs.
  • Second block: the rotated solution is kept when its SCF converges with ESA(after) < ESA(before) − E_CONVERGENCE; otherwise the SCF converges once more from the orbitals before the rotation. The SI step, properties and gradients follow the final solution.
  • C2H4 at 90°, BH&HLYP/6-31G, SSR(2,2) with the all-α determinant, from a localized seed (the active pair of the delocalized solution rotated by 45°, n = 2): without the option the SCF stays there, ESA = −78.351265591745 Eh, na = 2; with it x = 1, θ* = −45°, and the SCF reaches ESA = −78.362111811377 Eh, na = 1, the solution of the 0° → 90° restart chain (first two blocks above).
  • HF/6-31G(d), seed built the same way from the HF delocalized solution, REKS_USE_TRAH with REKS_GVB_DIIS false: the localized solution, ESA = −77.884884825216 Eh, lies below the delocalized one, −77.879948708032 Eh; the SCF from the rotated orbitals (θ* = 45°) returns to the localized solution, and the rotation is rejected (third block).
