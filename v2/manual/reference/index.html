18. Option Table

GUESS_ACTIVE_WINDOW is a general SCF option; the others are REKS options. Seven options have an REKS_-prefixed alias, given under the option name; setting both names is an error.

Active space

Option Default Meaning
REKS
[N, M]		 — (required) Active space [N, M]: N active electrons in M active orbitals; selects the catalog.

Catalog

Option Default Meaning
REKS_GEMINAL_WIDTHS
array		 [] (all 2) Width (orbital count) of each geminal, N/2 integers summing to M; selects the catalog reks{N}{M}_u{w0}{w1}….

SA pool

Option Default Meaning
SA_REKS_CONFIGS
array · alias REKS_SA_CONFIGS		 catalog sa_default pool on 2S = 0 SA-REKS configuration pool: one block (flat list) or one block per spin manifold (nested list) of names, indices or bulk tokens.
SA_REKS_WEIGHTS
array · alias REKS_SA_WEIGHTS		 uniform 1/n Weights of the SA pool entries, configurations first, then the sa_reks_extra determinants; non-negative, summing to 1.
SA_REKS_EXTRA
array of arrays · alias REKS_SA_EXTRA		 none Extra Slater determinants of the SA ensemble, as occupation vectors; each has its own weight, carries no FON and enters no SI cassette.

SI cassettes

Option Default Meaning
SI_REKS_CONFIGS
array · alias REKS_SI_CONFIGS		 one full-block cassette, lowest manifold SI-SA-REKS cassettes: the configuration sets whose secular equations give the states, in groups per spin manifold.
SI_REKS_PRINT_STATES
int		 5 States per cassette whose per-state and pair tables are printed; 0 = none, -1 = all.
SI_REKS_STORE_STATES
array of int · alias REKS_SI_STORE_STATES		 all; the first 10 if M ≥ 6 and > 10 configurations States per cassette whose properties are stored on the wavefunction (arrays, Molden and cube files); 0 = none, -1 = all.
SI_REKS_OVERLAP_CUTOFF
double		 1e-10 Overlap eigenvalues s ≤ cutoff · smax of the SI basis are treated as null space and dropped.

Spin manifolds

Option Default Meaning
SA_REKS_2SPIN
array · alias REKS_SA_2SPIN		 ladder, lowest manifold Spin manifold 2S of each SA block, one integer per block.
SI_REKS_2SPIN
array · alias REKS_SI_2SPIN		 ladder, lowest manifold 2S of each SI group; more than one entry requires the 3-level si_reks_configs form.

State properties

Option Default Meaning
SI_REKS_ANALYSIS
array		 all blocks except multipoles > 2 State-property blocks of the SI states to compute, print and store (moments, charges, bond indices, NTO, exciton, …).
SI_REKS_ANALYSIS_CHANGE_MIN
double		 0.1 Smallest state-to-state change of a charge or bond index that is printed.
SI_REKS_PROPERTY_FOR
array of arrays		 [] States, per cassette, whose dipole, quadrupole, charges and bond indices are evaluated with the relaxed (CP-REKS) density.
REKS_EKT
bool		 false Enables EKT: ionization energies, pole strengths and Dyson orbitals of the si_reks_property_for states or of the SA ensemble.
REKS_EKT_OCC_TOL
double		 1e-6 Cutoff on the density eigenvalues: those at or below it are dropped from the EKT metric.

Gradients and couplings

Option Default Meaning
SI_REKS_GRAD
array of arrays		 [] (SA ensemble) Roots whose analytic gradients are computed, per cassette; the first listed root is followed (CURRENT ENERGY, returned gradient).
SI_REKS_NAC
array		 [] Root pairs [I, J] per cassette whose nonadiabatic couplings and conical-intersection topography are computed.
REKS_CPREKS_CONV
double		 1e-9 Residual threshold of the CP-REKS (Z-vector) solver. reks_cpreks_maxiter (200) bounds its rounds.
REKS_CPREKS_MAXITER
int		 200 Maximum number of rounds of the CP-REKS (Z-vector) solver; exceeding it stops the run with the residual reached.
REKS_GRAD_DEGEN_TOL
double		 1e-6 Gap below which a requested root is flagged as quasi-degenerate.
REKS_CI_TOPOGRAPHY_GAP
double		 5e-3 Largest gap at which the topography table of a NAC pair is printed.

Guess

Option Default Meaning
GUESS_ACTIVE_WINDOW
array		 [] (off) MOs of the read guess placed in the active columns, one token per active orbital: 0-based index, HOMO-k or LUMO+k.

FONs

Option Default Meaning
REKS_FON_INTERP_DELTA
double		 0.4 Parameter δ of the factor f(n_p n_q) that multiplies the coupling term of each geminal in the REKS energy.
REKS_<L>_FON
double		 -1.0 each Lower bound on the free FON n_p of every geminal of one FON generation (reks_n_fon, reks_m_fon, …); negative disables it.

FON micro-solver

FON micro-solver

Option Default Meaning
REKS_FON_MICRO_NR_MAXITER
int		 20 Newton iteration cap per geminal block per SCF iteration.
REKS_FON_MICRO_LS_MAXITER
int		 20 Armijo backtracking (step halving) cap inside one Newton step.
REKS_FON_MICRO_CONVERGENCE
double		 1e-12 Step-norm convergence threshold.
REKS_FON_MICRO_MIN_EIGENVALUE
double		 1e-8 Floor on the absolute eigenvalues of the reduced Hessian; negative curvature is flipped.
REKS_FON_MICRO_BOUND_MARGIN
double		 1e-8 Margin m of the SCF FON box [ℓ, 2 − m] kept by the FON micro-solver and the TRAH step; must lie in (0, 1).
REKS_FON_MICRO_BOUNDARY_SKIN
double		 0.05 A generation-0 multi-start seed landing within this distance of 0 or 2 counts as boundary-trapped and loses to an interior minimum.

Convergence engines

Option Default Meaning
REKS_USE_TRAH
bool		 false Trust-region Newton (TRAH) step on the active–active rotations and FONs: warm-up before GVB-DIIS, or the whole SCF without it.
REKS_GVB_DIIS
bool		 true GVB-DIIS accelerator of the orbital optimization, in the formulation set by reks_diis_formulation.
REKS_DIIS_FORMULATION
CFM|ORBITAL		 ORBITAL GVB-DIIS formulation: extrapolation of the orbital-rotation generators κ, or of the composite multishell Fock matrix (CFM).
REKS_GVB_DIIS_START
int		 3 First SCF iteration of GVB-DIIS; earlier iterations run the level-shifted burn-in or TRAH.
REKS_DIIS_ACTIVATION
ITERATION|GRADIENT		 ITERATION Criterion for ORBITAL GVB-DIIS to take over from the TRAH warm-up: the iteration count alone, or also the orbital gradient.
REKS_DIIS_CFM_ACTIVATION_GORB
double		 1e-3 Orbital-gradient norm ‖g_orb‖_F below which GVB-DIIS takes over from the TRAH warm-up.
REKS_GVB_ROBUST_VERDICT
bool		 true Enables the post-hoc verdict that rewinds extrapolated GVB-DIIS steps whose orbital gradient grows.
REKS_GVB_LEVEL_SHIFT
double		 1.0 (CFM only) Shell gap of the multishell Fock matrix in the CFM formulation of GVB-DIIS.

Level shift

Option Default Meaning
LEVEL_SHIFT_ADAPT
bool		 true Adaptive base of the staircase level shift: decays while the orbitals are stable, grows back up to level_shift on swaps or strong mixing.

GVB-DIIS conditioning chain (expert)

Option Default Meaning
REKS_DIIS_COND_ANGLE_FILTER true Enables the angle filter with stale-drop that prunes near-dependent and stale GVB-DIIS error vectors.
REKS_DIIS_COND_ANGLE_CUTOFF 0.1 Angle-filter cutoff c_s: smallest sine of the angle to the kept differences for a GVB-DIIS error vector to stay.
REKS_DIIS_COND_STALE_DELTA 1e-4 Stale-drop threshold δ: GVB-DIIS error vectors with norm above the newest norm / √δ are dropped; 0 switches it off.
REKS_DIIS_COND_KAPPA_BYPASS 1e9 Condition number of the GVB-DIIS error matrix above which the SVD-conditioned solve replaces the plain bordered solve.
REKS_DIIS_COND_SVD_RCOND 1e-8 Relative singular-value cutoff of the SVD-conditioned GVB-DIIS solve.
REKS_DIIS_COND_COEFF_NORM_MAX 1e3 Bound c_max on the GVB-DIIS coefficient norm |c|², also used by the angle filter to drop near-duplicate error vectors.
REKS_DIIS_COND_TIKHONOV true Enables the Tikhonov ridge on the SVD-conditioned GVB-DIIS solve.
REKS_DIIS_COND_TIKHONOV_SCALE 0.0 Ridge magnitude of the Tikhonov-regularized GVB-DIIS SVD solve; 0 applies no ridge.

GVB-DIIS monitors / verdicts (expert)

Option Default Meaning
REKS_DIIS_MON_VERDICT_RHO 1.5 Verdict trip ratio: a GVB-DIIS step is rewound when ‖g_orb‖ exceeds this multiple of its maximum over the recent iterates.
REKS_DIIS_MON_VERDICT_STREAK 3 Consecutive verdict rewinds without a new best iterate before GVB-DIIS restarts from the best iterate.
REKS_DIIS_MON_SUPPRESS_WINDOW 3 Iterations after a GVB-DIIS rewind, restart or switch during which the verdict is suspended.
REKS_DIIS_MON_NONMONOTONE_M 3 Depth M of the nonmonotone references of the GVB-DIIS monitors: max ‖g_orb‖ and min E_SA over the last M iterates.
REKS_GVB_GATE_STREAK 2 Consecutive iterations meeting the energy and gradient thresholds before GVB-DIIS reports convergence.
REKS_DIIS_GUARD_LATCH_GRACE 3 Consecutive iterations without the basin signal after which the GVB-DIIS outcome guard clears its basin latch.
REKS_DIIS_GUARD_LANDING_TOLERANCE 1e-12 Relative tolerance at which a GVB-DIIS rewind landing counts as a repeat (best E_SA and best ‖g_orb‖ reproduced).
REKS_DIIS_MON_PROGRESS_EPS 1e-2 Sufficient-decrease fraction ε: a GVB-DIIS iterate counts as progress only if ‖g_orb‖ ≤ (1 − ε) × best ‖g_orb‖.
REKS_DIIS_FON_BRANCH_CUTOFF 0.1 FON displacement from the best iterate at or above which the GVB-DIIS guard reads an energy drop as a basin transition.
REKS_DIIS_RESTART_BUDGET 2 GVB-DIIS monitor restarts without sufficient improvement allowed before the monitors stop and rewind once to the best iterate.
REKS_DIIS_MON_CYCLE true Enables the GVB-DIIS no-progress / step-cap monitor, which restarts from the best iterate.
REKS_DIIS_MON_CYCLE_WINDOW 12 Iterations without a new best ‖g_orb‖ before the GVB-DIIS cycle monitor restarts from the best iterate.
REKS_DIIS_MON_CYCLE_CAP_STREAK 3 Consecutive ORBITAL step-cap hits before the GVB-DIIS cycle monitor restarts.
REKS_DIIS_ORB_BASE_MAP_DAMP 0.6 Damping α of the ORBITAL GVB-DIIS Newton step from the re-anchored frame after a restart.

Geminal delocalization

Option Default Meaning
REKS_GEMINAL_DELOC
bool		 false After the SCF, rotates generation-0 geminal pairs to their IPR minimum and reconverges; kept if it converges to a lower E_SA.

Reporting

Option Default Meaning
REKS_REPORT_LEVEL
int (1–5)		 2 Verbosity of the REKS output, 1–5: from the SCF trace and energetics up to per-iteration solver traces and intermediate matrices.
