Install

REKS Studio is a branch of Psi4 and builds with the Psi4 CMake build; the configuration catalogs are installed with it (§6).

# clone the branch
git clone --branch kk/reks.studio https://github.com/ConstLike/psi4.git
cd psi4

# set up build dependencies
conda env create -f environment.yml -n p4env311
conda activate p4env311

# configure and build
cmake -S. -Bobjdir -DCMAKE_INSTALL_PREFIX=/path/to/install
cmake --build objdir --target install -j$(nproc)

macOS, last line: cmake --build objdir --target install -j$(sysctl -n hw.ncpu)

Check the build

In objdir: ctest -L reks; every test passes within its own tolerances.

Then run psi4 reks22_h2.dat (download from Worked inputs) and compare S0 with the table there: they agree within the energy convergence threshold of the run, 10−6 Eh (Psi4 default; the input sets none); the last printed digits depend on the BLAS library and the number of threads.

Changes

Psi4 d40267fc2, 2026-10-13

  • One-electron SI couplings are Slater–Condon elements over the Fock matrices of the microstates, the bra/ket mean for an excitation (SI Hamiltonian and overlap); SSR energies and state properties follow from them.
  • SI gradients and NAC are analytic with meta-GGA functionals (Nuclear gradients of SSR states, Nonadiabatic coupling vectors); Laplacian-dependent meta-GGAs are rejected with an input error.
  • NTO holes, NDOs, state natural orbitals and EKT eigenvectors are in a canonical basis of each degenerate span (Natural transition orbitals, Natural orbitals and occupations of the active space).

Method name and computational details

Name the method SSR (SI-SA-REKS, §1); in a paper give the printed label kSI-lSA-REKS(N,M) (SI cassette), the functional as printed in the XC evaluation line, and the basis. The label carries only counts: name the SA-pool configurations with their weights and the cassette configurations as printed; defaults may change between revisions (Changes).

Report:

  • the printed blocks ==> REKS Studio setup <==, => SA pool <=, => Pairing schemes (geminal orbitals) <=, => SI pools <=, ==> State interaction: setup over the union of the SI cassettes <==, which hold these names and weights;
  • every REKS option set to a value other than its default (column Default of §18), and always SA_REKS_WEIGHTS, SI_REKS_OVERLAP_CUTOFF, REKS_CPREKS_CONV, GUESS_ACTIVE_WINDOW, REKS_<L>_FON, REKS_GEMINAL_WIDTHS;
  • the Psi4 options basis, puream, dft_spherical_points, dft_radial_points, scf_type, df_basis_scf, e_convergence, d_convergence;
  • the full input file (the whole options block and the geometry) in the SI; it also covers Psi4 options outside the list above
  • the functional name with its dispersion suffix, e.g. bhhlyp-d3bj
  • whether coupling damping was applied (Coupling damping below 100 % exact exchange)
  • the seed orbitals (Seed orbitals) and the C1 point group
  • optimization and dynamics: every argument of the driver call, defaults included; simplest is the whole driver script in the SI (Geometry optimization, Surface hopping)
  • PyUNIxMD and libdlfind versions (Requirements)
