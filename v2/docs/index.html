Installing REKS Studio and configuring an ensemble

A working reference for building the package and controlling the state-averaged and state-interaction ensembles it runs. For the method itself — why REKS Studio exists and how it stays fast — see the overview page.

Installation

REKS Studio is currently a development branch of Psi4, not yet a standalone package or conda release. Building it follows Psi4's own CMake-based build process. The configuration catalogues are shipped as binary files in psi4/share/psi4/reks_catalog/ and installed with Psi4 — nothing extra to run afterward.

# clone the branch
git clone --branch kk/reks.studio https://github.com/ConstLike/psi4.git
cd psi4

# set up build dependencies
conda env create -f environment.yml -n p4env311
conda activate p4env311

# configure and build
cmake -S. -Bobjdir -DCMAKE_INSTALL_PREFIX=/path/to/install
cmake --build objdir --target install -j$(nproc)
Note. This branch is research software under active development. Interfaces and keyword names may change before it's merged upstream.

Running a job Manual §1

Once built, REKS runs as an ordinary Psi4 reference — no separate binary or import. Set reference to reks, give the active space as [N, M], and call psi4.energy() as usual.

import psi4

mol = psi4.geometry("""
0 1
C   0.000000   1.301509  -2.315529
C   0.000000  -1.301509  -2.315529
...
units bohr
""")

psi4.set_options({
  "basis": "aug-cc-pVTZ",
  "reference": "reks",
  "reks": [4, 4],

  "sa_reks_configs": ["PPS1", "OSS1", "OSS2"],
  "sa_reks_extra": [[1, 1, 1, 1, 0, 0, 0, 0]],
  "si_reks_configs": [["PPS1", "OSS1", "OSS2", "OSS3", "OSS4"]],
})

E, wfn = psi4.energy("bhhlyp", return_wfn=True)

Keyword reference

Keywords marked with an alias have a REKS_*-prefixed second name (e.g. sa_reks_configs / reks_sa_configs) — set one or the other, never both. Defaults are noted where a keyword can be left out entirely.

Reference & active space Manual §5

reference

Set to reks to enable the method.

reks[N, M]

Active space: N electrons in M orbitals. The molecule multiplicity must be the canonical MS value (1 for even N, 2 for odd); any other value is an input error. Spin manifolds are selected by sa_reks_2spin / si_reks_2spin, not by the molecule block.

reks_geminal_widthsdefault: all 2

Orbital count of each two-electron geminal; length N/2, each in [2, 8], sum M. Selects the catalogue reks{N}{M}_u{w0}{w1}…, e.g. reks [4, 5] with [2, 3].

Note. Each active space is a pre-generated catalogue: (2,2), (4,4), (6,6), and with reks_geminal_widths (2,3)[3], (2,4)[4], (4,5)[2,3], (4,6)[3,3]. Any other (N, M) fails at load time.

Configuration names & bulk tokens Manual §4

Every configuration in the catalogue has a name of the form <TYPE><index>, e.g. PPS1, OSS2, T_PPS3; a member of a spin-polarized set is named <TYPE>_<k>, e.g. DOSS_SPS_0. You rarely need the full list — an unknown name in a config keyword makes REKS Studio print every valid name and type of the manifold the block is bound to — but the type prefixes are worth knowing:
PPS

The perfectly-paired singlet: every geminal Φ0. Every catalogue has at least one.

OSS, DOSS, TOSS

Configurations with 1, 2, 3 open-shell-singlet geminals. DOSS occurs in (6,6); TOSS only as TOSS_SPS in (6,6).

DES, DDES, TDES

The same 1, 2, 3 count for doubly-excited geminals; TDES occurs in (6,6) only. Compound types combine both: OSS_DES, DOSS_DES, OSS_DDES.

T_, TT_, TTT_ prefix

Number k of triplet-coupled geminals; the configuration belongs to the manifold 2S = 2k, e.g. T_PPS3, TT_SPS_0. In (2,2) the only 2S = 2 configuration is T1.

SPS tag

Marks a spin-polarized configuration; the trailing _k is its member index in an orthogonalized set, e.g. DOSS_SPS_0, DOSS_SPS_1.

Anywhere a config name is expected — in sa_reks_configs or si_reks_configs — these bulk tokens also work, so you rarely have to spell out individual names:
"full"

The entire configuration block of that manifold.

a type name"PPS", "OSS", "DOSS" …

Every configuration of that type in the manifold, case-insensitive; lettered types of the generalized-geminal catalogues (OSSa, Ta) included.

"single-scheme:N"

Every configuration of geminal-pairing scheme N (default scheme 0) plus the spin-polarized base configurations. Several indices can be unioned: "single-scheme-1-2-3".

"mixed-scheme:N"

The SSR state set on scheme N — that scheme's single-excitation configs plus every open-shell-singlet config of the manifold plus the spin-polarized base configurations.

"sps"

Just the spin-polarized base configurations.

a pattern"*" / "?"

Every configuration name it glob-matches.

"exclude:X"SI cassettes only

Subtracts whatever X names (any token above) from the rest of the cassette, e.g. ["full", "exclude:sps"]. An SA block, being a weighted list rather than a set, doesn't accept exclude:.

Note. A PSithon (.dat) input can't use a literal : inside an array element — write scheme indices with - or _ instead, e.g. single-scheme-1-2.

State-averaged (SA) ensemble Manual §5

The configurations whose orbitals are jointly optimized in the SCF step.
sa_reks_configsalias: reks_sa_configs

The SA configuration pool — a flat list for one spin manifold, or a list of lists to declare a block per manifold. Unset: the catalog's default 2S = 0 pool (PPS + OSS).

sa_reks_2spinalias: reks_sa_2spin

2S of each SA block, one integer per block. Without sa_reks_configs only [0] is accepted (input error otherwise); for higher-spin states on the default ensemble use si_reks_2spin.

sa_reks_weightsalias: reks_sa_weights

Weight for each SA pool entry, configurations first, then any extra determinants. Must be non-negative and sum to 1. Left unset, weights are distributed equally.

sa_reks_extraalias: reks_sa_extra

Extra determinants, e.g. the all-α determinant, given as occupation vectors. Each joins the SA ensemble with its own weight, adds its energy to ESA and shapes the orbitals; it carries no FON and never enters an SI cassette.

State-interaction (SI) ensemble Manual §5

Defined independently of the SA pool — mixed afterward to produce the final multi-state energies.
si_reks_configsalias: reks_si_configs

The SI configuration groups ("cassettes") that form the secular equations. Left unset, one cassette spans the full config block of the lowest manifold.

si_reks_2spinalias: reks_si_2spin

2S of each SI group; more than one entry requires the 3-level si_reks_configs form.

si_reks_print_statesdefault: 5

States per cassette whose per-state and pair tables are printed; 0 = none, -1 = all.

si_reks_store_statesalias: reks_si_store_states

States per cassette whose properties are stored on the wavefunction (array variables, Molden, cube files); one integer per cassette, 0 = none, -1 = all. Default: all, except 10 for cassettes with M ≥ 6 and more than 10 configurations. The eigenproblem is always solved at full dimension.

si_reks_analysis

State-property blocks to compute: DIPOLE, QUADRUPOLE, MULTIPOLE(n), TRANSITION_DIPOLE, TRANSITION_QUADRUPOLE, E_TDM_VEL, M_TDM, MULLIKEN_CHARGES, LOWDIN_CHARGES, TRANSITION_CHARGES, MAYER_INDICES, WIBERG_LOWDIN_INDICES, NO_OCCUPATIONS, DENSITIES, RADICAL, NTO, EXCITON, FRAGMENT_COUPLINGS, ALL. Unset: all blocks except multipoles above order 2. []: TRANSITION_DIPOLE and NO_OCCUPATIONS only.

si_reks_analysis_change_mindefault: 0.1

Smallest state-to-state change of a charge or bond index that is printed.

si_reks_overlap_cutoffdefault: 1e-10

Overlap eigenvalues s ≤ cutoff · smax of the SI basis are treated as null space and dropped.

Spin manifolds (2S > 0) Manual §7

Every configuration is the total MS = 0 component of its manifold, so one set of orbitals serves every manifold. A run's sectors are the union of the 2S values declared by SA blocks and SI groups.
triplet states

si_reks_2spin: [2] without config lists: SA = default 2S = 0 pool, SI = full 2S = 2 block. sa_reks_2spin: [2] without sa_reks_configs is an input error.

several manifolds

Nested lists, one block or group per 2S, e.g. sa_reks_configs [[PPS1, OSS1], [T_PPS1]], si_reks_configs [[["full"]], [["full"]]], si_reks_2spin [0, 2]. The SA ensemble is optimized jointly; each SI group is diagonalized separately.

state labels

S0, S1, … for 2S = 0; T1, Q1, Sp1, N1, U1, Tr1 for 2S = 2, 4, 6, 8, 10, 12 (root k → label k+1).

output

With two or more manifolds the report prints Spin-state energetics: gap and J = −Gap / (2Shigh) for H = −2J SA·SB, between the lowest states of adjacent manifolds. Array variables: REKS HEISENBERG J, REKS HEISENBERG J SPINS; per-sector energies REKS SECTOR s SSR ENERGIES K=e (s > 0).

Gradients, couplings & relaxed properties Manual §5

Analytic SI-state gradients and nonadiabatic couplings via the coupled-perturbed REKS (CP-REKS) response. List-of-lists options mirror si_reks_configs: inner list e refers to cassette e.
si_reks_grad

0-based roots whose gradients are computed, one inner list per cassette, e.g. [[1, 0], []]; an inner list [-1] = all roots of that cassette; a scalar element (flat [-1]) is an input error. The first root of the first non-empty inner list is followed: it defines CURRENT ENERGY and the returned gradient. Unset: SA ensemble, or the lowest root of the first si_reks_nac pair list.

si_reks_nac

Root pairs [I, J] per SI cassette, [[[I, J], ...], ...], or ALL; e.g. [[[1, 2]], []] couples S1 and S2 of cassette 0. A flat [[I, J]] is an input error. Publishes SSR NAC I J CASSETTE e and the conical-intersection topography (g, h, pitch, asymmetry, tilt).

si_reks_property_for

States whose properties are evaluated with the relaxed density: dipole, quadrupole, charges, bond indices. Entries: root indices or labels, ranges, lists ("S0..5", "T1"), inside per-cassette inner lists, e.g. [["S0..1"]]; a flat list is rejected.

reks_ektdefault: false

Extended Koopmans ionization energies, pole strengths and Dyson orbitals for the states of si_reks_property_for, otherwise for the SA ensemble. reks_ekt_occ_tol (1e-6) drops small density eigenvalues.

reks_cpreks_convdefault: 1e-9

Residual threshold of the CP-REKS (Z-vector) solver. reks_cpreks_maxiter (200) bounds its rounds.

reks_grad_degen_toldefault: 1e-6 Eh

Gap below which a requested root is flagged as quasi-degenerate.

reks_ci_topography_gapdefault: 5e-3 Eh

Largest gap at which the topography table of a NAC pair is printed.

Guesses & restarts Manual §8

REKS jobs converge far more reliably from a previous wavefunction than from a cold guess, so most production runs are chained restarts. Restarting uses ordinary Psi4 machinery; the keyword below selects which read orbitals form the active space.
# restart_file with a .npy file sets guess READ; to_file writes next.wfn.npy
E, wfn = psi4.energy("bhhlyp", restart_file="prev.wfn.npy", return_wfn=True)
wfn.to_file("next.wfn")
guess_active_window

Moves the listed MOs of the read guess into the active columns by column swaps, one token per active orbital in active-column order: 0-based MO indices or HOMO-k / LUMO+k, e.g. ["HOMO-1", "HOMO", "LUMO", "LUMO+1"]. Requires guess read (set automatically by restart_file with a .npy file); C1 only. If basis projection drops a read MO as linearly dependent, REKS warns that the active-window layout may no longer match.

Tip. If SCF converges instantly to a suspiciously wrong energy right after a restart, this is almost always the symptom — check the Molden output, then fix the active window rather than the whole guess.

Fractional occupation numbers (FONs) Manual §9

Each geminal pair carries FONs (n_p, n_q) with n_p + n_q = 2, optimized every SCF iteration with n_p in [floor, 2 − margin].
reks_fon_interp_delta

Parameter δ of the factor f(n_p n_q) that multiplies the coupling Δ of each geminal in the energy. Default 0.4.

reks_n_fon … reks_z_fon8 keywords, one per FON generation

A lower bound on the free FON n_p of every geminal of that generation (FON set n: PPS, DES, DDES, TDES; m: OSS, OSS_DES, OSS_DDES; u: DOSS, DOSS_DES). Setting reks_m_fon: 1.0, for instance, restricts n_p of every generation-1 geminal to [1.0, 2 − margin] (margin = reks_fon_micro_bound_margin, 1e-8) — it stays free and is optimized within that range, it is not fixed at n_p = n_q = 1. A bound of 1.0 excludes n_p < n_q; n_p may still reach 2. Negative (the default) disables the bound.

Delocalization penalty Manual §11

An optional energy term E_pen = λ Σi ΣA pA(i)² added to the SA energy, with pA(i) the population of active MO i on atom A. A positive λ penalizes localization and drives the SCF to the delocalized solution, the intended REKS solution: Σ p² decreases (H4, REKS(4,4): 1.1128 at λ = 0, 1.0669 at λ = 0.05).
reks_deloc_ipr_penalty

Coefficient λ (Ha) of the penalty. Default 0.0 (off); λ < 0 is an input error. With λ ≠ 0 the analytic gradient is unavailable; gradient() requires dertype=0.

reks_deloc_ipr_method

Population analysis used by the penalty: LOWDIN or MULLIKEN. Default LOWDIN.

Solver & convergence Manual §10

Three cooperating engines drive REKS's orbital/FON optimization — a plain level-shifted burn-in, an optional trust-region warmup, and the GVB-DIIS accelerator that normally finishes the job. Defaults work well for most systems; most users only ever touch level_shift.
reks_use_trah

Use trust-region Newton (TRAH) optimization of the active–active orbital rotations and the FONs as a warmup before GVB-DIIS takes over, or as the whole SCF if reks_gvb_diis is off. Default false.

reks_gvb_diis

Use the GVB-DIIS accelerator for orbital optimization — the default engine. Default true.

reks_diis_formulation"CFM" | "ORBITAL"

ORBITAL (default; Ionova & Carter 1995, Sethio et al. 2024) extrapolates skew-symmetric rotation generators directly and skips Fock diagonalization each step. CFM extrapolates the composite multishell Fock matrix instead (Muller et al. 1994).

reks_gvb_diis_start

SCF iteration at which GVB-DIIS takes over from the burn-in (or from TRAH). Default 3.

level_shift_adapt

When true (default), the base of REKS's staircase level shift equals level_shift through iteration 3, then decays toward a floor of 0.01 after iterations without orbital swaps and with small active mixing, and grows by 1.5× (up to level_shift) after iterations with swaps or active mixing above 0.30. False holds it at level_shift every iteration. Unset, REKS sets level_shift 0.6 and level_shift_cutoff 0.0. The shift acts on Fock-diagonalization steps only, not on ORBITAL GVB-DIIS steps.

Note. 23 further reks_diis_* / reks_gvb_* options (angle filter, SVD conditioning, rewind and restart monitors) are expert settings; see the manual. reks_report_level 4 shows which monitor fires.

Reporting Manual §12

reks_report_level1–5

Verbosity of the run report. 1 = no REKS blocks: the Psi4 SCF trace, energetics, the Molden summary and the returned gradient remain. 2 (default) = setup, pools, SCF trace, energetics, SI Hamiltonian summaries, adiabatic states, properties, state summary, spin-state energetics; no microstate energies. 3 = + SI Hamiltonian term counters, a references block, and config-axis arrays (SSR COEFFICIENTS, SSR HAMILTONIAN, …) stored as wavefunction variables. 4 = + per-iteration solver traces and, per cassette, microstate energies, the FON table, the Lagrangian/ERI table and the SI Hamiltonian and overlap matrices. 5 = + per-iteration Fock active blocks and microstate energy computation.

Troubleshooting Manual §13

Each symptom links to its entry in the manual: what the output prints, then what to do.

  • Instant convergence to a wrong energy after a restart
  • SCF hits maxiter or continues unconverged
  • SCF oscillates or cycles
  • The FONs of a geminal invert (n_p < n_q)
  • A FON pinned at a bound, symmetry-broken charges
  • Active orbitals localize on one fragment
  • Unknown configuration name or type
  • An (N, M) that fails to load
  • Ghost states and a collapsed SI spectrum
  • Quasi-degenerate roots
